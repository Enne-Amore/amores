## 📂 Estrutura do Projeto

 ```plaintext
 amores/
 ├── css/                    # Arquivos CSS
 │   ├── estilo.css
 │   ├── video.css       
 ├── fonts/                  # Arquivos das fontes utilizadas  
 │   ├── AmoreMIO.ttf
 ├── img/                    # Imagens utilizadas 
 ├── view/                   # Arquivos JavaScript
 │   ├── lumity.html
 │   ├── mavee.html
 │   ├── mioshun.html
 │   ├── raineda.html
 ├── index.html              # Arquivo principal de renderização
 ├── README.md
 ```


## 🛠️ Instalação Local

 1. **Clone o repositório**
 
 No terminal, rode o seguinte comando:
 
 ```bash
 git clone https://github.com/ennetechdesign/amores.git
 ```
 
 2. **Entre no arquivo "index.html"**
 
 3. **Rode o arquivo principal de renderização:**
 
 Clique com o botão direito do mouse e selecione a seguinte opção:
 
 ```bash
 Open with Live Server
 ```
